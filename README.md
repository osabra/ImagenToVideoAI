# ImagenToVideoAI

Aplicación Android para convertir una imagen en un vídeo mediante IA.

## Estado actual

- Selección de imagen desde el dispositivo.
- Vista previa de la imagen.
- Campo para describir el movimiento.
- Duración de 5, 10 o 15 segundos.
- Botón de generación y estado de progreso.
- Flujo preparado para conectar un backend de Image-to-Video.
- GitHub Actions para compilar automáticamente la APK de debug.

## Próximo paso

Conectar el backend de generación IA. La clave de API debe mantenerse en el servidor y nunca incluirse directamente en la APK.
